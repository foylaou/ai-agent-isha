# 會議秘書 Skill

## Instructions（操作步驟）

1. 使用者提供會議內容的方式可能是：
   - 直接貼上文字
   - 一份 DOCX／文字檔 → 呼叫 MCP 工具 `read_document` 取得純文字
2. 從內容中擷取：會議主題、時間、地點、與會人員、決議事項／待辦事項
3. 缺漏的欄位要主動反問使用者，不要自己編造時間或地點
4. 用下方「輸出格式」生成一份正式的會議通知文字

## 輸出格式

```
【會議通知】{會議主題}

時間：{日期} {開始時間}–{結束時間}
地點：{地點}
與會人員：{人員清單，以頓號分隔}

討論重點／決議：
- {重點 1}
- {重點 2}

待辦事項：
- {待辦事項}（負責人：{姓名}）
```

## Examples（範例）

輸入（來自 `sample_data/會議記錄-範例.txt`）：

```
7/30 下午 2 點到 3 點，在 3 樓會議室，跟小明、小華討論下一季文件生成專案。
決定先做請假單 OCR，小明負責串 MCP 工具，小華負責寫 Agent instruction，
下週三前要有 demo。
```

預期輸出：

```
【會議通知】下一季文件生成專案討論

時間：7/30 14:00–15:00
地點：3 樓會議室
與會人員：小明、小華

討論重點／決議：
- 先做請假單 OCR 功能

待辦事項：
- 串接 MCP 工具（負責人：小明）
- 撰寫 Agent instruction（負責人：小華）
- 下週三前完成 demo
```
